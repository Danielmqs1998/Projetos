## **W-ERP**
Sistema de ERP básico com funcionalidades como:

![wERP - Sistema ERP na WEB](URL_da_Imagem)

- Autenticação de usuário com token temporário
- Gráficos de dados
- Cadastro e manutenção de clientes e produtos (CRUD)
- Listagem sob demanda
- Pré-visualização de imagens
- Filtros em tempo real

Tecnologias utilizadas: 
  -> Front-end: JSF; Primefaces; HTML; CSS; Javascript; JQuery
  -> Back-end: Java; Spring Boot; JWT Token
  -> Banco de Dados: Mongo DB
  -> DevOps: Docker

![wSTORE - Plataforma e-commerce](URL_da_Imagem)

## **W-STORE**
Plataforma de e-commerce web simples com funcionalidades como:

- Autenticação de usuário
- Integração de produtos com o ERP
- Listagem de produtos
- Layout responsivo

Tecnologias utilizadas: 
  -> Front-end: Angular; Bootstrap; Material UI; HTML; CSS; Typescript
  -> Back-end: Java; Spring Boot
  -> Banco de Dados: Mongo DB
  -> DevOps: Docker

![wSAC - Sistema de atendimento ao cliente](URL_da_Imagem)

## **W-SAC**
Sistema de atendimento ao cliente via chat com funcionalidades como:

- Autenticação de usuário
- Mensagens em tempo real
- Integração com a plataforma wSTORE

Tecnologias utilizadas: 
  -> Front-end: React; Material UI; HTML; Tailwind CSS
  -> Back-end: Typescript; Node.js
  -> Banco de Dados: PostgreSQL
  -> DevOps: Docker
